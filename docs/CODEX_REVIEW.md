# Independent review (Codex) — findings and disposition

**Date:** 2026-10-11 · **Reviewer:** OpenAI Codex CLI 0.160.0 (`codex exec`, read-only sandbox, reasoning effort high), three separate runs, each given the specification and the code but not the implementer's conclusions.

**Scope of each run:** (1) server core — domain, contracts, application use cases, D1 adapters, API; (2) agent side — pipeline, tool policy, provider adapters, fetchers, SEC tools, runner; (3) browser side — registry, renderers, SPA, E2E, Lean proofs, import-boundary checker.

**Result:** 52 findings (22 server core, 17 + 1 low agent side, 12 browser side and proofs). 46 are fixed with a regression test each. 5 are fixed in part, with the remaining gap stated in the tables below. 1 is not fixed and is recorded as an accepted V1 risk. The reviewer also examined lease fencing, duplicate completion, the guarded D1 writes, SQL parameterisation, owner scoping, JWT and CSRF checks, the SSRF policy and the XSS paths, and reported no defect in them.

Limits of the review itself: the sandbox could not run vitest, Playwright, wrangler or Lean, so reproductions were in-memory; nothing live (Access, CLIs, SEC, OpenRouter) was exercised.
