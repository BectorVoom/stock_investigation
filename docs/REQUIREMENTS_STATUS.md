# Requirements status

**As of 2026-10-12.** Passing CI does not imply product acceptance (hard gate 10). This file records what is delivered, on what evidence, and what is not.

**Operating mode.** The workspace runs locally by default (`bun run start`, ADR-0006). The Cloudflare deployment the specification describes is postponed: a locked, unconfigured deployment exists, and signing in through Cloudflare Access was never exercised. Section 5.1's hosting and the identity-provider requirement are therefore **not met in the default mode by decision of the owner**; local mode has no sign-in and relies on loopback-only access.

Legend: **Met** — implemented and covered by tests that can fail. **Partial** — the mechanism exists but something the requirement needs is missing or unverified. **Not met** — not implemented.
